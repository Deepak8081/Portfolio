A modern, high-performance personal portfolio website built with React, Vite, and Tailwind CSS. Showcases full-stack engineering projects, skills matrix, experience timeline, and direct contact inquiry channels.

---

## ✨ Key Sections
- **Hero Section**: High-impact developer introduction with animated badges and primary resume/contact CTAs.
- **Skills Matrix**: Categorized tech stack (Frontend, Backend, Databases, Cloud & DevOps).
- **Featured Projects**: Interactive project cards with live demo links, GitHub source repositories, and stack tags.
- **Contact Desk**: Interactive contact form with direct social and WhatsApp reachability.
- **Production Optimized**: Single-page application configured with `vercel.json` SPA rewrites for instant edge delivery.
